# أخبار العائلة — iOS أصلي / Native SwiftUI 2.0.0

افتح `FamilyNews.xcodeproj` في Xcode. اختر App > Signing & Capabilities > Personal Team، ثم الآيفون واضغط Run.

هذه واجهات SwiftUI أصلية وليست WKWebView أو Capacitor. لا تحتاج npm أو CocoaPods أو حزم خارجية. iOS 17 أو أحدث. نفس معرف التطبيق: `com.martadha3li.familynews`، ويمكن تثبيتها كتحديث بنفس الفريق دون حذف التطبيق السابق. يلزم تسجيل الدخول مجددًا لأن الجلسة الأصلية تحفظ بأمان في Keychain.

## الواجهات

- تسجيل الدخول والتسجيل وتأكيد البريد واستعادة كلمة المرور.
- الأخبار والصور 4:5 والإعجابات والتعليقات والمنشن، والنشر والتعديل والإخفاء والحذف وفق الصلاحيات، ومسودات الصحفي وموافقة المدير.
- الإعلانات المجدولة بأنواعها، تظهر كعنوان يفتح التفاصيل.
- دردشة نصية عامة وخاصة ومجموعات وأحداث، بحث بالأسماء أو الجوال، رد/نسخ/تعديل/حذف الرسائل، تاريخ أقدم، وأعضاء المجموعات.
- الملف الشخصي وصورة العرض، تغيير البريد وكلمة المرور عبر تأكيد البريد، وطلب تغيير الجوال من المدير، وسجل النشاط والمنشن.
- شجرة القرابة والأسماء المشابهة، التعريف بالأعضاء ومراجعة الموافقة.
- إدارة الأعضاء وضوابط العائلة وخيارات القرابة والإعلانات وطلبات تغيير الجوال وقياس التخزين والضغط والتنظيف بعد تأكيد صريح.

## الأمان والحدود

تستخدم الواجهة مفتاح Supabase القابل للنشر فقط. الصلاحيات وفصل الدردشة بين الجنسين والتحقق من العضوية تطبق في قاعدة البيانات الحالية لكل طلب. لا تنقل هذه الحزمة البيانات ولا تغير الاشتراك أو RLS. الصور بتوقيع قصير الأجل، والجلسة في Keychain، وطلبات الشبكة بذاكرة مؤقتة عابرة دون حفظ رسائل أو صور على القرص.

تُحدّث الرسائل دوريًا عندما تكون الشاشة نشطة؛ هذه النسخة لا تتضمن استقبال إشعارات APNs في الخلفية. روابط تأكيد تغيير البريد وكلمة المرور تكمل التحقق من الصفحة الآمنة الحالية. التسجيل لا يعد إثبات نسب.

## التحقق

يُبنى أرشيف iOS على macOS في GitHub Actions بواسطة `.github/workflows/native-ios.yml`. الفحص `checks/core-checks.py` يشغّل دوال Swift الفعلية الخاصة بتطبيع الجوال وJSON والتواريخ والترميز، ويفحص عدم تضمين محرك ويب أو مفتاح مميز.

نجاح البناء لا يعني أن كل شاشة اختُبرت على آيفون فعلي. راجع تقرير التسليم لنتيجة البناء الأخيرة وحدود اختبار الجهاز.
