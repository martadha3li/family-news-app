# أخبار العائلة

واجهة عربية مستقلة تعمل مع Supabase وتُستضاف باستخدام Sites. أصل المشروع: https://github.com/martadha3li/family-news-app.

الحسابات الجديدة تنتظر اعتماد المدير بعد تأكيد البريد. بيانات الأعضاء وصلاحياتهم في قاعدة البيانات، وليس في بيانات المستخدم القابلة للتعديل. الصور خاصة وروابطها مؤقتة لعشر دقائق، وتضغط الواجهة الصورة إلى 400 كيلوبايت. الأخبار قابلة للإخفاء والاستعادة.

نسخة PWA للمتصفح، وليست تطبيقًا منشورًا في المتاجر. لم تُفعّل خدمة مدفوعة. التخزين المجاني يخضع لحصص الاستخدام؛ سعة 2000 مستخدم وخبر لا تضمن عدد الزيارات المتزامنة أو نقل الصور.

check-permissions.sql اختبارات معاملات تُلغى بالكامل ولا تترك بيانات. نجحت اختبارات ملكية المدير، نشر الصحفي، تفاعل العضو، عزل المعلق والزائر، منع ترقية العضو لنفسه وحماية السجلات المخفية. اجتاز app.js وsw.js فحص JavaScript. فحص Supabase الأمني لم يُرجع تنبيهات.

لم يتوفر اختبار مرئي للواجهة في بيئة التنفيذ؛ لم يُختبر تسليم رسالة التسجيل إلى البريد ولا رفع صورة فعلي بحساب حقيقي.

schema.sql يوثق التغييرات المنجزة، ولا يُعاد تشغيله تلقائيًا على قاعدة سبق تطبيقه عليها.

## الإعلانات وحذف الأخبار
إدارة الإعلانات للمدير فقط. تدعم بداية مستقبلية ونهاية محددة أو مدة بالساعات. تظهر الإعلانات النشطة مثبتة أعلى مساحة الأعضاء، وتُخفى عند انتهاء المدة. يتحقق الخادم أيضًا من وقت العرض وصلاحية العضوية. تُراجع الإعلانات آليًا كل 30 ثانية، مع مؤقت محلي لانتهاء الإعلان أثناء بقاء الصفحة مفتوحة.
زر الحذف النهائي للمدير، مع طلب تأكيد. تحذف قاعدة البيانات التعليقات والإعجابات التابعة تلقائيًا. زر الإخفاء يحتفظ بالسجل لاستعادته.
الإعلانات الحالية نصية؛ لا تتضمن صور إعلانات.
