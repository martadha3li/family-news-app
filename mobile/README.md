# التطبيق القابل للتثبيت

حزمة Capacitor بواجهة محلية مضمّنة للأندرويد والآيفون؛ البيانات والصور تبقى في مشروع Supabase الحالي.
المعرّف: com.martadha3li.familynews

## البناء الآلي
GitHub Actions يبني APK تجريبيًا على ubuntu-24.04، ويجهز مشروع iOS وأرشيفًا غير موقّع على macos-latest.
لا تستخدم الشيفرة أي مفتاح Supabase إداري ولا تحفظ كلمة مرور المستخدم.
نسخة Android التجريبية موقعة بمفتاح اختبار تلقائي، وليست نسخة متجر.
نسخة iOS غير الموقعة لا يمكن تثبيتها على جهاز حقيقي؛ تتطلب شهادة وتوقيع Apple وملف provisioning مناسب.

## تجربة الاستخدام
الدخول بالبريد وكلمة المرور داخل التطبيق مباشرة.
رابط البريد يعود إلى موقع الويب؛ يمكن استخدام حقل تأكيد البريد داخل الحزمة لنقل رابط التحقق إليها. الربط العميق للتطبيق غير مفعّل في هذه النسخة.
إجراء النسخ الاحتياطي يستعمل تنزيل المتصفح الحالي، ويحتاج اختبارًا خاصًا على WebView لكل منصة قبل اعتماد نسخة المتجر.
تحديث الواجهة المضمّنة يحتاج إصدار حزمة جديدة؛ الأخبار والتعليقات والإعلانات تتحدث مباشرة من قاعدة البيانات.

لم يتم تفعيل أي اشتراك مدفوع أو نشر في متجر. يلزم اختبار على أجهزة فعلية قبل الإصدار النهائي.
